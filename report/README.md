# Report

This folder contains the final report source and generated PDF for AIAA 3201 Project 3: Video Object Removal & Inpainting.

## Files

```text
report/
├── main.tex          # report source
├── main.pdf          # compiled report
├── references.bib    # BibTeX entries for project references
└── figures/          # flowcharts and comparison figures used in the report
```

## Format

The project handout requires a CVPR-style 6--8 page report with:

- Abstract and Introduction
- Related Work covering the required reference list
- Method with high-quality flowcharts
- Experiments with quantitative tables and qualitative figures
- Conclusion, limitations, and future work

The official `cvpr.sty` is not included in this repository. Therefore `main.tex` uses a CVPR-like two-column `article` setup with:

- `twocolumn`
- letter paper
- 0.75 inch margins
- Times-style font via `newtxtext,newtxmath`
- BibTeX references

This keeps the report Overleaf/MiKTeX compatible without requiring external CVPR template files.

## Build

From this folder:

```powershell
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Or from the repository root:

```powershell
cd report
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Expected output:

```text
report/main.pdf
```

## Figures

Flowcharts are generated by:

```powershell
python scripts\generate_flowcharts.py
```

They are written to:

```text
report/figures/pipeline_overview.png
report/figures/pipeline_part1.png
report/figures/pipeline_part2.png
report/figures/pipeline_part3.png
```

Comparison figures are copied from `results/` into `report/figures/`, for example:

```text
report/figures/comparison_bmx-trees.png
report/figures/comparison_tennis.png
report/figures/comparison_wild_video.png
report/figures/comparison_blackswan.png
report/figures/comparison_bus.png
report/figures/comparison_car-shadow.png
```

Figures use `keepaspectratio` in `main.tex` so they display fully without cropping.

## References

`references.bib` contains the reference database used by the report. The project brief requires 17 core references. Extra implementation/data references such as Ultralytics or DAVIS may exist in the `.bib`, but only cited entries appear in the final bibliography.

If strict 17-reference output is required, remove extra citations from `main.tex` and rerun BibTeX.
